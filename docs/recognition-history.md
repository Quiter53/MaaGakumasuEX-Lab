# 2026-10-11 卡牌识别修复的实际方法

核对聊天「修复商店卡牌识别」、当时保存的修复说明，以及现有 square_identity.py、hand_identity.py 与 train_hand_identity.py 后，原始商店识别修复没有重新训练或替换 YOLO。

原流程分两层：cards.onnx 检测牌的位置与可用/推荐状态；卡图匹配再识别卡名。原日志已检测到 18 个牌位，后续卡名匹配覆盖不足、区域混入图标和缩放偏移才是主要问题。

修复将仅 436 张基础卡图的索引，改为利用已有 2176 份包含变体的卡图；提取卡面两个局部区域，避开费用、效果、强化与持续时间角标，进行小范围缩放/平移对齐。两个区域须指向同名同稀有度，分别通过相似度和不同卡名候选差距。参考特征缓存后复用，整页优先识别，仅不确定卡读取详情，删牌与交换提交继续核对选中卡名。

当时记录的实机结果：商店 4/4，约 0.53 秒；删牌列表 18/18，约 1.50 秒，均无需逐张点图。9 张历史真实截图的 92 个牌位通过回放。该结果适用于记录中的样本，不表示所有场景准确率为 100%。

后续手牌识别沿用参考卡图库：无遮挡时使用整体卡面，4～5 张重叠时只比较可见局部。train_hand_identity.py 对参考图生成亮度、位移与噪声扰动，再拟合拒识阈值；训练/合成留出使用不同卡名分组与随机种子。它不训练神经网络，没有反向传播，也不生成新的 cards.onnx。card_fingerprints.npz 是参考图库，hand_identity_calibration.json 是阈值参数。

10 张对应的历史截图原以 `.png.bmp` 保存，在 2026-10-24 重新找回并转成像素完全一致的 PNG。它们位于 fixtures/hand，与源码中的 tests/fixtures/hand_identity_labels.json 配套。使用 lab.py evaluate-hand 可复现人工牌框下的卡名评估；这不测试检测器能否找到所有框，不等同于端到端实机验证。

神经网络重新训练仍需要完整 YOLO detection 标注集和 `.pt` 权重，不能把这组手工卡名评估截图或已有 ONNX 当作原训练集与训练检查点。
