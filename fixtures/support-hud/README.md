# 支援卡重复与日程体力回归

来自用户授权加入 Lab 的反馈截图及本机历史回放。窗口截图按客户端范围裁切到 720×1280；重复弹窗保留既有 720×1279 裁切。租借者昵称与个人签名已遮盖，卡片、重复标识、等级和按钮保持原像素。不是原始设备帧，也不是连续实战录像。

`cases.json` 给出预期数值；租借列表顺序为首张重复、无重复、当前可见项全重复。控制器在模拟滚动后切换到无重复页面，所有点击只记录，不发送给游戏。体力保留 0.90 门槛，验证文字行定位、格式与范围；负样本复用相邻 hand/deck 目录。

执行 `lab.py --source <产品源码> test --output <新目录>` 自动回放，产品源码需为 v2.3.5 或包含该回归脚本的后续版本。Lab 默认子模块仍固定 v2.2.0，换电脑时需另检出所测版本并传入 `--source`。8 张图的摘要见 `SHA256.json`；原图另存本地 `datasets/local/support-hud-20261115`，不上传。
