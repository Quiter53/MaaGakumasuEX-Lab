# Modern UI 交互原型

[打开 HTML 文件](MaaGakumasu-UI-Modern-Preview.html)。下载后用 Edge 或 Chrome 打开即可；图片、样式和脚本均已内嵌，无需安装项目依赖。

这是用于评审新版界面布局和交互的独立原型。页面中的任务、运行日志、配置和出牌模拟均为演示数据；修改仅存在于当前页面内存，刷新后恢复。原型未连接游戏或正式客户端，页面中的“自动保存”等文字是界面示意。

## 本次修复

- 侧栏和偏好设置共用主题更新入口，深浅模式的图标、文案与选中状态同步刷新。
- 导航按钮统一撑满侧栏容器，收起时设置、主题与导航图标居中对齐。
- 阶梯曲线在节点所在回合使用该节点的权重，保持到下一个节点前；大曲线和列表小曲线使用同一组折线顶点，实际阶梯包含水平和竖直段。
- 拖动坐标通过 SVG 的实际屏幕变换换算，适应窗口缩放与留白；拖动跨过其他节点后仍编辑原节点，同回合重合时保留刚拖动的节点。修复双击删除时节点被提前重绘的问题。
- 两个重置入口统一名为“默认权重”，恢复当前卡牌各回合权重为 50。默认、前期和后期模板均适配总回合数；缩短总回合数时合并重合节点。
- 弹窗取消、关闭/×、菜单和提示退出沿用玻璃高光、轻缩放与淡出风格；删除配置页签、规则、任务和名单卡牌时增加离场反馈。删除立即更新数据，动画副本不可交互且会自动清理。
- 快速重开弹窗或菜单会取消旧关闭计时，避免新内容被误关；支持 Escape 关闭，减少动态效果设置下即时完成退出。
