# Modern UI 交互原型

[打开 HTML 文件](MaaGakumasu-UI-Modern-Preview.html)。下载后用 Edge 或 Chrome 打开即可；图片、样式和脚本均已内嵌，无需安装项目依赖。

这是用于评审新版界面布局和交互的独立原型。页面中的任务、运行日志、配置和出牌模拟均为演示数据；任务等未接入保存的修改仅存在于当前页面内存，刷新后恢复。出牌规则页点击“保存”后会将全部预设保存到浏览器 localStorage；面板布局及实时画面显隐在调整后自动保存，刷新后保留；更换浏览器或文件位置不会自动迁移。原型未连接游戏或正式客户端，任务配置中的“自动保存”等文字是界面示意。

[Avalonia 原生实现方法与可复用提示词](AVALONIA-NATIVE.md) 已从原型中独立整理，包含现有工程入口、控件映射、动效与验收要求。

## 第四轮：规则页保存与控件对齐

- 顶部右侧改为蓝色“保存”，保存全部出牌预设并在刷新后恢复；保存失败时提示原因。曲线区域保留唯一的“默认权重”，仅重置当前牌的权重。
- 所有数字步进器的加减号改为对称 SVG 图标，去除按钮默认内边距，避免字体基线导致偏移。
- “最多保留一张”与“自定义再动”使用等宽两列，分别从左侧和中间起排，文字与开关垂直居中。

已在 Chrome 156 检查 1600×1000、1280×800 下的图标中心与两列位置，以及保存、刷新恢复和默认权重重置；深浅主题已目视核对。原型保存仅作用于当前浏览器，不写入正式程序配置。

## 第三轮：可自定义的工作台布局

- 默认按参考图排列：左上任务列表、左下任务说明，中间任务设置，右侧运行日志；实时画面默认关闭。
- 拖动面板标题或标题旁手柄：移向目标的上半／下半区域可在同列叠放；移向左右边缘可分出新列。拖动中实时预览，目标及周围面板自动分配尺寸，源位置自动补满，松手后保存。
- 拖动列间分隔条调整相邻列宽，拖动同列面板间分隔条调整高度。布局统一计算最小尺寸与剩余空间；窗口不足以容纳时工作区可滚动。
- 拖动只改变位置和尺寸，不重建面板输入内容。按 Escape、在工作区外松手、指针取消或窗口失焦会取消此次移动。
- 聚焦标题旁的移动按钮后，方向键可上下排序或移到相邻列。保留最大化／还原、实时画面开关和减少动态效果支持。
- 顶部“恢复布局”恢复默认排列、尺寸及实时画面关闭状态，不清空当前任务设置。

第三轮于 2026-10-31 在 Chrome 156 实际验证：同列和跨列实时让位、拖动保留未提交输入、刷新恢复、分隔条缩放、最大化／还原、实时画面显隐、键盘移动、取消与越界回退、切页保留、侧栏收起后的重新布局、无效存储回退和减少动态效果。默认布局在 1600×1000、1280×800 下均未溢出；固定随机种子 81031 的 400 次连续布局计算中，面板无重复、丢失或重叠，几何值有限且均位于分配边界内。深浅主题与拖动预览已目视检查。

## 第二轮：任务输入与完整选卡

按正式程序 v2.1.5（`d08174d3d6c0aecb34b8343397a8f19749a1e947`）的配置和原生控件补齐：

- 等待时间使用统一玻璃步进器，保留手动输入；范围 0～5 秒、最多两位小数、默认 1.5。页面其他数字输入隐藏不协调的浏览器微型上下箭头。
- 道具名称和选中状态分别更新，修复点击后名称被“已选/未选”覆盖的问题。两个道具默认均不选，与原任务配置一致。
- 移除自动自定义开关上下多余分隔线，以及标题栏的 Avalonia 技术说明按钮。
- 卡库从原型的 84 张补到正式程序的完整 456 张，使用对应缩略图和属性；图片仍全部内嵌。选卡器增加 8 项筛选、分页、结果数量、重置筛选、选中态和确认/取消，搜索保持焦点并正确处理输入法组字。
- 所有通用选卡入口复用同一选卡器。新建规则默认权重为 50，已有规则不能重复创建；国民配合目标可选择或清除。
- 回忆目标支持强化状态、绿豆下限、多个目标和重复条件校验；卡组提供角色卡、支援卡、四个普通卡槽，并按来源限制候选牌。
- 自动自定义读取原程序 247 条自定义卡牌资料，显示各选项次数、P 点费用与上限；支持上移/下移、拖动手柄排序及移除。
- 三类目标编辑器均使用独立草稿，保存才更新当前任务，取消保留原设置。目标默认留空，与原任务配置一致。

第二轮已在 Chrome 156 中实际检查：数字步进和非法输入、道具反复切换、8 项筛选与分页、输入法组字、重复规则、配合目标清除、槽位来源限制、目标保存/取消、自定义次数上限与拖动排序、空目标校验。深浅主题均检查，选卡器在 1600×1000 和 1280×800 下检查布局。原生实现方案尚未转成原生客户端代码。

## 本次修复

- 侧栏和偏好设置共用主题更新入口，深浅模式的图标、文案与选中状态同步刷新。
- 导航按钮统一撑满侧栏容器，收起时设置、主题与导航图标居中对齐。
- 阶梯曲线在节点所在回合使用该节点的权重，保持到下一个节点前；大曲线和列表小曲线使用同一组折线顶点，实际阶梯包含水平和竖直段。
- 拖动坐标通过 SVG 的实际屏幕变换换算，适应窗口缩放与留白；拖动跨过其他节点后仍编辑原节点，同回合重合时保留刚拖动的节点。修复双击删除时节点被提前重绘的问题。
- 第一轮将两个重置入口统一名为“默认权重”，恢复当前卡牌各回合权重为 50。第四轮已将顶部入口替换为“保存”，曲线内仍保留重置。默认、前期和后期模板均适配总回合数；缩短总回合数时合并重合节点。
- 弹窗取消、关闭/×、菜单和提示退出沿用玻璃高光、轻缩放与淡出风格；删除配置页签、规则、任务和名单卡牌时增加离场反馈。删除立即更新数据，动画副本不可交互且会自动清理。
- 快速重开弹窗或菜单会取消旧关闭计时，避免新内容被误关；支持 Escape 关闭，减少动态效果设置下即时完成退出。
